# SAM 3.1: a separate spatial evidence layer

The **SAM 3.1 masks** tab plays real segmentation output beside the original model experiment. Toggle between the sampled source and the overlay at the same playback position. The blue region and contour come directly from binary masks, without hand-drawn corrections.

The text prompt is `cardboard box`. [Meta SAM 3.1](https://huggingface.co/facebook/sam3.1) tracks the box through the opening motion. The seven-second source was sampled to 56 frames at 8 fps; the run returned one tracked object throughout. All masks are in `data/sam31-masks.npz`, with frame indices, source timestamps, object IDs, bounding boxes and pixel counts in `data/sam31-recorded.json`.

The film slows this sequence to half speed so the boundary changes are visible. It does not claim live camera throughput.

## Relationship to Jev

SAM answers a spatial question: where is the prompted object in each sampled frame? Jev scores the defined observations and actions. The eight Jev results still use their original unpainted inputs. No colored overlay was sent to Jev, and this update does not claim improved Jev accuracy from segmentation.

An unpainted region clip can be generated by `render_sam_masks.py` using a fixed rectangle around the masks with 32 pixels of padding. It is an optional experiment asset, not the source of the published Jev scores. A future controlled comparison should vary only the crop while holding frame selection, question and candidate answers fixed.

The mask is not a model attention map. Preserving the geometry and original input helps someone review what was localized; it does not expose Jev's reasoning. SAM can also segment incorrectly, especially around occlusion and small disconnected regions. This demo has no pixel-level ground truth or segmentation accuracy score.

## Reproduce

Install the [official SAM repository](https://github.com/facebookresearch/sam3) and its CUDA dependencies in an isolated environment, and obtain SAM 3.1 weights under Meta's access and license terms. We do not redistribute weights. The exact checkpoint revision and installed code commit are recorded in the JSON.

```sh
python scripts/segment_receiving.py \
  --sam-repo /path/to/sam3 \
  --checkpoint /path/to/sam3.1_multiplex.pt \
  --input assets/opening.mp4 \
  --output runs/sam31 \
  --prompt "cardboard box" --fps 8

python scripts/render_sam_masks.py runs/sam31
```

Rendering requires FFmpeg, NumPy and OpenCV. The segmentation wrapper filters only unsupported optional arguments forwarded to the installed `init_state` API; it does not alter model weights. It preserves every returned frame and fails if the sequence is incomplete.

The recorded session, prompt and propagation took **28.39 seconds**, excluding checkpoint loading, visualization encoding and Jev inference. This is one local GPU run. The film's **3.26-second** figure refers solely to the earlier Jev video request, not to a combined SAM-plus-Jev pipeline.
